【AimPulse 系統規格書】

一、 專案基本資訊
專案名稱：AimPulse (FPS 靈敏度換算與反應靶場)
專案類型：純前端互動式 Web 應用程式 (Single Page Application)
實作架構：單一檔案架構 (index.html 內嵌 HTML、CSS、JavaScript)
運行環境：主流現代瀏覽器 (Chrome, Edge, Firefox, Safari)
部屬方式：GitHub Pages 靜態託管

二、 專案背景與開發目標
射擊遊戲 (FPS) 玩家常面臨跨遊戲遊玩時手感不一致的問題，需透過靈敏度與硬體 DPI 的精準轉換維持肌肉記憶。同時，玩家在調整設定後往往需要立即驗證手感與反應狀況。
本專案將「跨遊戲靈敏度精算」與「沉浸式 2D 點擊反應靶場」整合於單一畫面中。針對視覺可見度與練習手感，全面優化標靶尺寸與全螢幕專注機制，並加入「開局 3 秒預備倒數 (3-2-1 Countdown)」機制、實時平均反應時間 (ms) 數據追蹤、完整的結算面板流程與一鍵分享功能。

三、 系統功能規格

1. 靈敏度換算模組 (Sensitivity Converter)
(1) 支援遊戲清單：
- Counter-Strike 2 (CS2)
- Valorant
- Apex Legends
- Overwatch 2

(2) 輸入參數：
- 來源遊戲 (Source Game)
- 滑鼠硬體靈敏度 (Mouse DPI，如 400, 800, 1600 等，提供快捷點擊鍵)
- 來源遊戲內靈敏度 (In-game Sensitivity)
- 目標遊戲 (Target Game)

(3) 計算演算法與公式：
- 基準 Yaw 值定義：
  * CS2 / Apex Legends：Yaw = 0.022 度
  * Valorant：Yaw = 0.07 度
  * Overwatch 2：Yaw = 0.0066 度
- 換算邏輯：
  * 目標靈敏度 = 來源靈敏度 * (來源 Yaw / 目標 Yaw)
  * 有效 DPI (eDPI) = DPI * 靈敏度
  * 360 度轉身物理距離 (cm/360) = (360 * 2.54) / (DPI * 靈敏度 * Yaw) = 914.4 / (DPI * 靈敏度 * Yaw)

(4) 輸出結果：
- 目標遊戲推薦靈敏度（四捨五入至小數點後 3 位）。
- 當前設定的 eDPI 與 cm/360 物理旋轉距離。

2. 互動式 Canvas 點擊靶場模組 (Mini Aim Trainer)
(1) 開局 3 秒預備倒數機制：
- 觸發時機：點擊「立即開始」、「全螢幕放大專注開始」或「再練一局」。
- 視覺反饋：畫布中央顯示全螢幕半透明遮罩，以霓虹大字依序倒數 3、2、1 與 GO!，每秒伴隨彈跳放大動畫。
- 音效提示：Web Audio API 頻率合成（3、2、1 為 440Hz 短音；GO! 為 880Hz 高亢發令音）。
- 狀態保護：倒數期間不生成標靶，點擊畫布不列入脫靶計算。

(2) 視窗放大與全螢幕專注機制：
- 雙軌顯示架構：支援瀏覽器原生 Fullscreen API 與劇院覆蓋備援模式 (theater-mode)。
- 標靶尺寸：
  * 常規視窗模式：標靶基礎半徑加大至 33 ~ 45 px（直徑約 66 ~ 90 px）。
  * 全螢幕放大模式：標靶半徑再放大 2.0 倍至 66 ~ 90 px（直徑約 132 ~ 180 px）。
- 退出機制：支援鍵盤 ESC 鍵與按鈕切換退出；30 秒倒數結束自動退出全螢幕以顯示結算。

(3) 頂部 HUD 即時數據儀表板：
- 剩餘時間：30 秒高精確度倒數（顯示至小數點後 1 位）。
- 命中 / 脫靶數：即時更新對比。
- 準確率 (%) = [命中次數 / (命中次數 + 脫靶次數)] * 100%
- 即時平均反應時間 (ms)：每次命中時動態累加計算平均耗時（未命中前顯示 --ms）。

3. 成績結算與分享模組 (Result Modal)
(1) 操作功能：
- 一鍵複製成績：格式化字串複製到剪貼簿。
- 再練一局 (Play Again)：關閉結算彈窗並重新觸發 3 秒預備倒數。
- 結束測試 / 返回主畫面 (Finish & Exit)：點擊右上角關閉鈕或下方結束按鈕，關閉彈窗並將畫布與數據重置為初始狀態。

(2) 段位評級機制：
- 命中 >= 45 且 準確率 >= 90%：S 級 (Radiant / The Global Elite)
- 命中 >= 35 且 準確率 >= 80%：A 級 (Diamond / Master)
- 命中 >= 25：B 級 (Gold / Platinum)
- 命中 < 25：C 級 (Bronze / Silver)

四、 技術實現規範
1. 單一檔案要求：全部 HTML、Tailwind CSS CDN、JavaScript 邏輯均封裝於 index.html。
2. 免外連多媒體依賴：介面圖示均採用 SVG 繪製，音效使用 Web Audio API 即時合成，無外部圖片或音檔資源請求。
3. 高解析度自適應：Canvas 透過 devicePixelRatio 與 getBoundingClientRect 即時校準點擊座標，無論螢幕如何縮放皆精準判定。
